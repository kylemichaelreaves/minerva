# spaCy / LatinCy model wheels for `minerva terms lemmatize`.
#
#   uv pip install -r lemma-models.txt      # or: make install-lemma-models
#
# These are deliberately NOT in `pyproject.toml`'s `lemma` extra, and that
# is the whole point of this file (#282).
#
# WHY THEY LIVE HERE
#
# `uv sync --locked` verifies the lock against `pyproject.toml`, and for a
# `direct+https` source that verification re-derives the package's metadata
# by fetching the wheel — for *every* URL dependency in the graph, no matter
# which extra is being installed. So `uv sync --locked --extra dev`, which
# installs two packages and no model, still reached github.com and
# huggingface.co on every CI job. A 429 from either failed the job, and with
# it the PR — including PRs whose diff is documentation.
#
# Measured, with a cold cache and no network:
#
#   uv sync --locked --extra dev --dry-run --offline   -> fails on the first URL wheel
#   uv sync --frozen --extra dev --dry-run --offline   -> succeeds, no network at all
#
# `--frozen` is NOT the fix: it skips the staleness check and would install a
# stale lock at exit 0, which is the hole #125 closed. Taking the wheels out
# of the resolution graph is. Nothing in `pyproject.toml` refers to them, so
# no `uv sync` resolves them, and `uv.lock` no longer contains a single
# github.com or huggingface.co URL. `tests/test_lemma_models_pinning.py`
# enforces both halves of that.
#
# WHAT THIS FILE MUST KEEP (#122)
#
# Leaving the lock means leaving `uv.lock`'s hash verification, so the
# integrity guarantees have to be carried here instead. Two rules, both
# enforced by that test:
#
#  1. Every entry carries a `#sha256=` fragment. `uv pip install` verifies
#     it, so a substituted wheel fails the install rather than executing.
#     A model wheel is a Python package: installing it runs its code.
#
#  2. The HuggingFace URLs are pinned to a **commit SHA**, never
#     `resolve/main`. `main` is a mutable branch — the bytes behind a
#     `resolve/main/<file>` URL can be replaced in place. This is not
#     hypothetical: `la_core_web_sm-3.9.4` was pinned at `resolve/main` and
#     has since been **deleted** from the repo (it now 404s; only 3.9.5 and
#     3.9.6 remain), which is why the version below is 3.9.6.
#
# The GitHub `releases/download/` URLs are already immutable by tag, but
# they carry `#sha256=` too — the fragment is what makes the guarantee
# checkable rather than assumed.
#
# ON A VERSION BUMP: update the URL, the `#sha256=`, and — for the LatinCy
# pair — the commit SHA in the path. `spacy`, `stanza` and `pyyaml` stay in
# the `lemma` extra; they are ordinary PyPI packages and cost nothing to
# resolve, so install that extra as well:
#
#   uv pip install -e '.[lemma]' && uv pip install -r lemma-models.txt
